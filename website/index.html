为什么是轻羽

在越做越重的时代，做一本简单的记事本

AI 时代查资料很容易，真正值得写下来的，是自己的心得、感悟和私密想法。很多笔记软件越做越重，塞满插件、协作与花哨排版；而够轻量的备忘录，又往往缺跨平台或同步。轻羽想把这两块补齐——像手写记事本一样纯粹，却能在你的每台设备上安心接着写。

像备忘录一样轻

没有插件市场，不用折腾花哨排版，打开就能写。标题、表格、待办随手就有，语法不碍眼。

全平台，且端到端加密

补齐轻量工具最缺的跨平台与同步。笔记在本机加密后再上传，私密想法在云端只剩密文，冲突时两份都会保留。

笔记就是本地文件

不锁进私有数据库。文件夹对应磁盘目录，每篇都是你硬盘里普通的 .md 文件，卸载软件也在，随时可以带走。

写作体验

该有的格式都有，
不用记一条语法

熟悉的三栏布局：左侧文件夹，中间按日期分组的列表，右侧正文。用过系统备忘录就能直接上手。

  • 表格直接点进单元格编辑，待办点一下就勾上
  • 脚注、数学公式和提示块随手就能插入
  • 流程图和思维导图直接画在笔记里（Mermaid、Markmap）
  • 输入 / 打开斜杠菜单，选择要插入的内容
  • 标题可折叠，⌘K 随时跳到任意笔记，正文也能全文搜索

随记

想到什么，
先记一句

不用起标题，也不用挑文件夹。随记按天排成一条时间线，像给自己发消息一样，记下一句感悟、一段书摘或一件要做的事。

  • 用 #标签 归类，可以按标签或只看待办筛选，也能搜索
  • 能附上图片，也能直接录一段语音
  • 重要的置顶；想展开写时，转成一篇正式笔记
  • 手机上长按桌面图标，直接打开随记或开始语音速记
  • 每条随记同样是普通的 .md 文件，和笔记放在一起

同步与隐私

不登录也能完整使用

笔记默认只存在你选的本地文件夹里。需要多台设备时，再挑一种方式同步。

省心

轻羽云

登录轻羽账号后开启。打开应用、保存笔记时会自动同步，之后每 3 分钟再同步一次。账号和存储空间在 账号中心 管理。

自己掌控

自定义 S3

填入你自己的 S3 兼容存储，AWS、Cloudflare R2、MinIO 都行。数据放在哪、留多久，完全由你决定。

在本机写作→ 用同步密码加密（AES-256-GCM）→ 云端只存密文→ 另一台设备解密

笔记、图片和附件都会加密。忘记同步密码又没有已解锁的设备时，云端数据将无法解开，请妥善保管。

不想用云同步？也可以直接把笔记目录放进 iCloud Drive、坚果云或 Dropbox，交给网盘同步。

常见问题

你可能想知道

轻羽收费吗？

应用本身免费，代码以 GPL-3.0 协议开源。不注册账号也能使用全部写作功能。轻羽云是可选的同步服务，用自己的 S3 或网盘同步不需要任何费用。

我的笔记存在哪里？

存在你选择的本地文件夹里。文件夹就是磁盘上的目录，每篇笔记是一个普通的 .md 文件，图片和附件放在旁边。卸载轻羽之后，这些文件原样还在。

忘了同步密码怎么办？

同步密码只保存在你的设备上，服务端无法帮你找回。如果还有一台已经解锁的设备，可以在那里重新设置；如果都没有，云端的加密数据将无法解开，但每台设备本地的笔记文件不受影响。

macOS 提示「无法打开」或「已损坏」？

macOS 版暂未做 Apple 公证。第一次打开被拦截时，请到「系统设置 → 隐私与安全性」，在下方找到轻羽并点「仍要打开」。Windows 安装包暂未签名，可能看到 SmartScreen 提示，点「更多信息 → 仍要运行」即可。

支持哪些 Markdown 语法？

GitHub 风格的表格、任务列表和删除线，以及脚注、KaTeX 数学公式、提示块、Mermaid 流程图和 Markmap 思维导图。写好的文件放到其他 Markdown 工具里也能正常显示。

有 iPhone 和 iPad 版吗？

界面已经适配好了，但 iOS 版暂未上架，上架后会在这里提供下载。Android 可以直接下载 APK 安装。
