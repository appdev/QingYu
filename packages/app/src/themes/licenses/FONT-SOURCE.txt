The bundled WOFF2 files are format-converted, Unicode-partitioned subsets
created solely for WebView webfont delivery. The upstream glyph outlines and
OS/2 weight class 400 are retained.

Because conversion and subsetting create a Modified Version under OFL 1.1,
the user-facing family, full, unique, and PostScript names were changed to the
non-reserved derivative name "Light Whisper ZhenKai". Copyright and upstream
attribution remain intact in the font metadata and this provenance file.

The upstream family provides this single real Regular weight. The theme keeps
semantic CSS requests such as 600 and 700 and permits only weight synthesis so
WebView can create emphasis without synthesizing italic or small-caps faces.
