# 轻羽 QingYu v0.1.0

轻羽的首个桌面版本，提供本地 Markdown 笔记库、文件夹管理、编辑与预览、所见即所得编辑、分屏、全文搜索，以及 S3 同步和创建系统日程。

## 下载

- macOS Apple Silicon：`macos_aarch64.dmg`。
- macOS Intel：`macos_x64.dmg`（文件名中的架构也可能显示为 `x86_64`）。
- Windows x64：`windows_x64-setup.exe`（文件名中的架构也可能显示为 `x86_64`）。
- Linux x64：`.deb` 或 `.AppImage`；需要 WebKitGTK 4.1，建议 Ubuntu 22.04 或更新版本。

安装包由本仓库的 GitHub Actions 从 `v0.1.0` 标签构建，全部平台成功后统一发布。

## 安装与已知边界

- macOS 使用临时签名，未进行 Apple Developer ID 签名和公证；系统可能阻止直接打开。Windows 安装包未进行代码签名，可能显示 SmartScreen 提示。
- 首次使用已有笔记库前建议保留备份。已有应用标识、笔记目录和同步格式保持兼容。
- Windows/Linux 的日程功能生成 `.ics` 文件交给默认日历软件确认导入，提醒是否生效取决于目标软件。
- 本次发布不包含 Android、iOS、Docker 镜像及独立 API 服务二进制。
- 自动化构建通过不代表完成所有平台的真机功能验收；已知功能和验证范围见仓库 README 及 `docs/`。
