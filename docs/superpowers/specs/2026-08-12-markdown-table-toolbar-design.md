# Markdown 表格工具栏视觉协调设计

## 背景

Markdown 所见即所得编辑器已经使用思源图标精灵替换缺失图标，但当前每个操作都显示独立边框，图标密度、分组关系和删除操作层级不够协调。用户已在视觉对比中选择 C1「功能分组型，删除按钮独立」。

## 目标

在保持现有思源主题、图标体系和表格编辑能力不变的前提下，统一 Markdown 表格工具栏的尺寸、间距、状态与功能分组，使其更接近思源原生紧凑型工具栏的视觉秩序。

## 非目标

- 不更换现有思源 SVG 精灵图标。
- 不新增或删除表格操作。
- 不修改表格尺寸、对齐、列宽、增删行列或删除表格的业务逻辑。
- 不修改 Markdown 源码格式和持久化数据。

## 视觉结构

工具栏从左到右分为四个独立容器：表格尺寸、左/中/右对齐、列宽模式、删除表格。组间间距为 8px；对齐组内三个按钮连续排列，其余组各包含一个按钮。删除表格独立成组，避免与列宽模式形成错误的功能关联。

每个分组使用 `1px` 主题边框、主题表面背景和约 `8px` 圆角。组内使用约 `3px` 内边距和 `1px` 间隔。单个按钮点击区域约为 `28px × 28px`，按钮圆角约 `6px`，图标统一为 `16px × 16px`。所有数值允许在实现时根据现有字体缩放机制等价换算，但桌面默认字号下的视觉尺寸必须与上述规格一致。

## 状态设计

默认状态使用 `--b3-theme-on-surface` 的低强调色，分组背景使用 `--b3-theme-background` 或等价主题表面色，边框使用 `--b3-border-color`。悬停和键盘聚焦状态使用 `--b3-list-hover` 背景。当前对齐方式和当前列宽模式使用 `--b3-theme-primary` 图标色及轻量选中背景，不额外增加高对比边框。删除按钮默认保持中性，仅在悬停或键盘聚焦时使用 `--b3-theme-error`；不得常驻红色。

工具栏继续沿用现有可见性策略：仅在表格悬停或表格内部获得焦点时显示，隐藏状态不接受指针事件。状态变化保留短促的透明度过渡，不增加位移、弹跳或缩放动画。

## 实现边界

表格控制逻辑继续由 `app/src/markdown/markra-core/codemirror/table.ts` 管理。实现可以为四个功能组增加明确的结构类名或包装元素，并在 Markra 基础主题中定义布局尺寸。思源主题颜色覆盖继续放在 `app/src/assets/scss/business/_markdown.scss`。图标继续通过 `createSiyuanMarkdownIcon` 创建，不手写新的 SVG。

桌面端和移动端共用相同分组语义。工具栏保持单行且完整显示，在宽度为 320px 的 Markdown 内容区域内不得撑宽页签、隐藏功能、换成第二行、产生工具栏自身横向滚动或覆盖表格内容。

## 可访问性

保留每个按钮现有的 `aria-label`、`title`、`aria-pressed` 和 `aria-expanded` 行为。分组容器只承担布局作用，不改变按钮的键盘焦点顺序。焦点状态必须在深色和浅色主题下清晰可见。

## 验证标准

- 结构测试确认四个分组存在，顺序为尺寸、对齐、列宽、删除，对齐组包含三个按钮，删除按钮独立。
- 图标测试继续确认所有按钮引用思源图标精灵。
- 状态测试确认当前对齐方式和列宽模式正确反映 `aria-pressed` 与选中样式。
- Electron 布局测试确认默认桌面宽度和窄窗口下工具栏不造成页签横向溢出，按钮尺寸与组间距符合规格。
- 在深色和浅色主题下进行视觉检查，确认图标居中、线宽协调、选中态不过度突出、删除操作仅在交互时显示警示色。
- 运行完整前端测试、TypeScript 类型检查和 ESLint。
