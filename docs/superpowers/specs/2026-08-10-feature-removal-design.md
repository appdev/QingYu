# 精简产品功能设计

## 1. 背景与目标

当前项目将作为尚未发布的新笔记软件底座。本次精简彻底删除 AI 与 Agent、语义搜索、闪卡与复习、云账号及思源官方云服务、收集箱，并保证应用不采集或外传遥测数据。删除采用纵向切片方式，同时清理前端入口、内核 API、模型、配置、数据结构、依赖、类型、快捷键和多语言文本，不保留兼容空实现或旧配置迁移。

## 2. 总体原则

- 删除功能的 API 不再注册，调用时自然返回 404。
- 产品尚未发布，不为已删除字段、数据表或文件格式增加兼容迁移。
- 保留本地访问认证、API Token、管理员与只读角色、TLS 等自托管安全能力。
- 保留内置 MCP Server，但删除 MCP 客户端、Agent 以及依赖内部 AI 配置或已删除产品功能的 MCP 工具。
- 保留本地数据仓库快照和第三方同步，不保留账号会员判断或官方云服务入口。
- 保留在线集市的必要内容读取和下载量展示，不主动上报客户端安装事件或设备标识。
- 不改写大批上游 PDF.js 代码，通过禁用配置、空发送实现和自动检查保证遥测不被采集或外传。

## 3. AI、Agent 与语义搜索

删除 AI 聊天、带操作的 AI 调用、Agent 会话与历史、Agent 前端操作、Skills 管理、模型列表与测试、AI 设置页、MCP 客户端连接及 OAuth、Embedding、Rerank、语义搜索、向量索引器和向量数据表。清理 OpenAI、Token 估算及仅被这些功能使用的依赖、环境变量、配置字段和类型。

内置 MCP Server 的 `/mcp` 端点继续存在，并继续要求本地认证、管理员角色和非只读模式。保留笔记本、文档、块、属性、数据库、普通搜索、文件、同步、导入导出和插件动态注册等通用 MCP 工具。删除依赖内部 AI Provider 的图片理解与生成能力、Agent 专用工具、收集箱工具和其他只能服务于已删除模块的工具。插件向 MCP Server 注册通用工具的能力继续保留，独立于 AI 配置的 Secrets 能力继续保留。

## 4. 闪卡与复习

删除桌面端和移动端的闪卡入口、复习页面、制卡菜单、牌组管理、快捷键和设置页。删除 `/api/riff/*` 路由、闪卡模型、配置、导入和同步挂钩、块返回值中的闪卡状态，以及 `github.com/siyuan-note/riff` 依赖。删除相应类型和多语言文本，不保留闪卡数据加载或迁移逻辑。

## 5. 云账号与官方云服务

删除云账号登录、二次验证、登出、激活码、试用、停用、会员状态和账号设置页。删除启动阶段和窗口初始化中的云用户请求、云空间信息、容量提醒、官方云资源上传、官方同步 Provider、官方云同步目录管理、云端快照上传下载和云端仓库清理入口。

保留访问认证码和 API Token，它们属于本地与自托管安全边界，不属于云账号。保留 S3、WebDAV 和本地文件系统同步，并移除它们对云账号或会员状态的依赖，使三种 Provider 可直接配置和使用。保留本地数据仓库初始化、快照创建、标签、比较、检出、单文件恢复和本地清理能力。

集市索引、版本检查或其他明确保留的公共内容服务不因删除账号与官方同步而自动删除；只有账号、会员、官方存储、官方同步和官方备份链路属于本节删除范围。

## 6. 收集箱

删除桌面和移动端收集箱入口、Dock 模型、收集箱 API、速记列表和详情、删除与移动逻辑、速记保存笔记本及路径配置、相关类型、快捷键、多语言文本和 MCP 收集箱工具。与普通每日笔记、文档创建和外部 API 无关的功能不受影响。

## 7. 遥测边界

目标是应用不采集、不缓存、不主动外传使用行为、诊断数据、安装事件或设备标识。项目已有的 Google Analytics 和 Sentry 删除状态必须保持。PDF.js 的 `reportTelemetry` 上游事件代码可以保留，但发送端必须为空实现且遥测配置固定禁用。

在线集市继续读取下载次数并在卡片、详情和排序中使用。客户端安装成功后不得调用下载次数增加接口，不得发送 `systemID` 或等价设备标识。下载量应由集市服务端基于包文件请求日志统一统计。用户主动执行的包索引读取、README/图标/预览读取、安装包下载和更新检查属于功能请求，不作为遥测删除。

## 8. 插件与在线集市

保留插件安装、卸载、更新、启用、禁用、前端插件 API、内核插件生命周期、插件 RPC 和插件向 MCP Server 注册工具的能力。删除仅用于内部 AI Agent 发现和调用插件操作的插件扩展点及其类型、注册表和清理逻辑。

保留在线集市的 GitHub 仓库地址、索引、README、图标、预览、Stars、Issues、下载次数展示、按下载量升序和降序排序，以及插件、挂件、主题、图标和模板的安装更新链路。只删除客户端安装次数上报，不删除下载次数读取和展示。

## 9. 启动与运行数据流

应用启动不再初始化云用户、AI Provider、Embedding 索引器、MCP 客户端、Agent、闪卡或收集箱。内核继续初始化普通索引、本地认证、MCP Server、插件、集市、本地仓库和选定的第三方同步 Provider。设置页只呈现仍可工作的模块；同步页只提供 S3、WebDAV 和本地文件系统选项。

已删除功能不会出现菜单、Dock、设置项、快捷键、命令或 API。保留功能不得通过残留配置间接触发已删除服务。删除范围内出现的错误通过彻底消除调用路径解决，不增加“功能已禁用”兼容分支。

## 10. 实施切片

实施按依赖方向分为六个切片：AI、Agent 与语义搜索；闪卡与复习；云账号与官方云服务；收集箱；遥测与集市安装上报；最终依赖、类型、i18n 和死代码清理。每个切片先移除消费者和入口，再移除 API 与模型，最后移除配置、数据结构和依赖。MCP Server、第三方同步、本地认证和本地仓库是跨切片保护边界。

## 11. 验证标准

- 使用静态搜索确认被删除的前端入口、API 路由、配置字段、Go/TypeScript 引用、环境变量和依赖均不存在。
- 运行 MCP Server 相关 Go 测试，确认 `/mcp`、通用工具、权限保护和插件动态工具注册继续工作。
- 运行 S3、WebDAV、本地文件系统同步、本地仓库、本地认证和集市相关的针对性 Go 测试；不编译或重启内核二进制。
- 运行 `cd app && pnpm run lint`；遵守项目规则，不运行 `pnpm build` 或 `pnpm dev`。
- 清理所有语言文件中的删除功能文本后，运行 `python scripts/check-lang-keys.py`。
- 检查网络调用，确认云账号、官方存储与同步、AI、Agent、Embedding、Rerank、语义搜索和集市安装次数上报地址均不可达；GitHub 及集市内容读取、S3、WebDAV 和用户主动配置的 MCP 请求继续允许。
- 检查最终差异，确认没有意外删除 MCP Server、插件运行时、本地快照、第三方同步、本地认证、普通全文搜索或 PDF 阅读能力。

## 12. 非目标

本次不进行品牌重命名，不替换集市来源，不重写编辑器、数据库、同步协议或插件系统，不删除内置 MCP Server，不新增多人协作，不处理尚不存在的发布版本数据迁移，也不提交、推送、发布或部署代码。
