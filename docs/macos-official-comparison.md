## 所见即所得代码与 Mermaid 渲染（2026-11-10）

## Mermaid 深色配色修正（2026-11-10）

《调用关系图.md》的自定义浅黄、浅蓝等节点填充会与原版深色主题的浅色文字及边框冲突。使用该文档的标签兼容副本，在 WebKit 中按实际 SVG 测量：214 个节点中有 27 个文字对比度不足 4.5:1，24 个边框不足 3:1。上一轮仅核验默认主题，遗漏了文档指定的填充色；本次验证增加实际 SVG 对比度、主题切换和缓存重绘。

仅在我们的 `public/preview.js` 中补充渲染后处理：保留节点填充，按实际背景调整对比度不足的文字及边框。原版资源文件、Markdown 和图形布局均不改。这是为可读性主动偏离原版的配色修正。

修正后 7 个图表、214 个节点的最低文字对比度为 6.30:1、最低边框对比度 5.17:1，连线对预览背景最低为 7.01:1。深色→浅色→深色以及缓存重绘通过，作者指定的填充和源文保持不变；浅色配色沿用原版，本轮没有调整。测试新增彩色节点回归，共 15 项通过；macOS release 构建及构建资源的 WebKit 检查通过，独立桌面对比应用已更新并确认实际显示。证据位于 `artifacts/mermaid-contrast/`；当前处理覆盖不透明 RGB 纯色节点，渐变和半透明填充未纳入验证。

## 用户并排截图的补充修正

上一轮宽窗口样本不能覆盖窄窗口分屏；今后此处的验收同时保留整窗编辑与窄窗口分屏，且比较前先核对实际分隔线位置。本次没有修改全局工作流或用户偏好。

用户截图的问题已在原生窗口复现并定位：

1. 官方版保存的分屏比例为约 46.924%，我们的默认值为 50%，同样大的窗口不代表编辑区同宽。这会让删除线段落少折一行，从而使后面的引用、列表、表格提前一整行。对照时将我们的分隔线拖至相同位置；保留可拖动分隔线，没有把该用户比例硬编码为默认值。
2. 预览 iframe 自己的宽度小于 640px 时，会误触发手机规则，把左右留白由 28px 改成 24px；已去掉该覆盖，统一使用原版 28px。
3. 同步到第 1 行时，原先把第一个标题滚动到顶部，卷掉了其 10px 上边距。现在首行回到页面 scrollY=0，后续源行继续插值滚动。
4. `typography.css` 的引用块使用了发布后版本，字号小 1px、缩进不同。现在该文件与下载的官方 V4.8.0 逐字节一致；本轮核验的 47 个共享 CSS、字体和 JavaScript 文件均与发布版一致，清点结果纠正了首次记录的 48 个计数。

同宽原生预览复核（原始截图像素，2x）：H1 顶部 y=139，H2 y=355，引用文字 y=677，列表标题 y=805，表格标题 y=1283，代码标题 y=1674；两边这些坐标一致。编辑区断行位置一致，但软换行取整仍使后续正文有约 2–3pt 的累计差异。复选框的蓝色/灰色还受窗口是否激活影响，不当成字号或布局差异。

## 已定位的原因

### 编辑区几何参数不能直接按 CSS 等价换算

我们在 `src/style.css` 中设置 `line-height: 23.8px`，依据是原源码中的 `16 × 1.3 + 3`。但原版实际使用 `NSMutableParagraphStyle` 的 `lineHeightMultiple`、`lineSpacing`、最小/最大行高和 NSTextView 文本容器，和浏览器固定 `line-height` 的布局不是同一条路径。原生对照截图已经证实实际步长不同。

后续应以同一份样本的首行位置、连续行步长和折行位置校准，不能继续宣称 23.8px 已经等价于原版。

### 中文强调需要同步 HTML 处理链

官方运行时生成的 HTML 包含：

```html
<em lang="zh">以《聊斋志异·婴宁》之美，展现 Markdown 之妙</em>
```

妙言的 `MiaoYanCore/Emphasis.markCJK` 会识别中文、日文和韩文，并给 `<em>` 添加语言。共享 CSS 中的 `.heti em:not([lang])` 只让没有该属性的强调文本倾斜。我们当前生成普通 `<em>`，因而触发了错误的倾斜样式。

参考：[官方 Emphasis.swift](https://github.com/tw93/MiaoYan/blob/V4.8.0/Packages/MiaoYanCore/Sources/MiaoYanCore/Emphasis.swift)。当前项目对应入口为 `src/markdown.ts`。

### 对照版本不一致

我们参考的源码提交为 `9ce84b01bd5f6b23a7156e317b2a34a464e3df76`，官方发布版为 V4.8.0。复制的 `typography.css` 已包含发布后对引用块的更新：字号变小、padding 改为 12px。需要先明确以已下载的 V4.8.0 为验收基线，再统一资源和 HTML 处理行为。
