# 从文件管理器打开笔记

桌面安装包注册 `.md`、`.markdown`、`.txt`，作为可选编辑器，不修改系统默认应用。
在 Finder / 文件管理器中右键文件，选择“打开方式 → 轻羽”。也可以在应用里用“文件 → 打开文件…”（macOS `⌘O`，Windows / Linux `Ctrl+O`）。

外部文档按所在的真实目录复用窗口：同目录的第二份笔记在已有窗口中切换，不同目录才新建窗口。
切换前先保存当前编辑；保存失败或输入尚未完成时保留当前文档并提示，不丢弃输入。新文件会先重新读取目录，再切换到对应笔记。
文件已经在某个窗口编辑时，重复打开会激活该窗口；正文没有变化时保留编辑器的光标和撤销历史。目录路径通过系统规范化处理，符号链接入口归并到真实目录。
每个文档窗口有独立的临时工作区和文件监听：侧栏仅列出同一目录下的笔记，不递归扫描子目录，也不把文件导入笔记库。不在源目录创建 `.miaoyan` 索引。
正文编辑、重命名、新建笔记和复制笔记直接作用于源目录；临时模式不提供移动、删除和文件夹管理。
使用侧栏底部的返回按钮或 `⌘⇧W` / `Ctrl+Shift+W` 激活笔记库窗口，文档窗口仍保留。
关闭文档窗口时先保存该窗口，再释放它的工作区和监听，不会退出应用或关闭其他文档。
有文档窗口存在时，关闭主窗口会保存并隐藏主窗口，笔记库同步仍由它统一处理。
退出应用时先保存主窗口及所有文档窗口；未完成输入、保存失败或窗口无响应时取消退出，保留编辑内容。所有本地内容保存成功后执行原有的退出前同步，S3 失败或超时仍直接退出。

S3 会话始终绑定设置中的笔记库，打开外部文件不会改变配置或扩大同步范围。
如果原文件本来就在配置的笔记库内，修改仍会通过笔记库的文件监听被同步。
文件在其他程序中修改或删除时，旧内容不会直接覆盖回去；未保存的并发编辑会备份到应用数据目录的 `external-conflicts`，界面显示备份位置。
超过 4 MiB、损坏或不可读的文件以只读状态处理。

macOS 通过 `RunEvent::Opened` 接收冷启动和运行中的文件请求；Windows / Linux 通过启动参数及官方 Single Instance 插件转发到现有进程。
请求在主窗口初始化前暂存，文档窗口串行创建；打开新文档不会替换原编辑器，也不需要等待主窗口的 S3 同步。
移动端保留现有笔记库行为，本功能暂不注册移动端文件打开入口。
