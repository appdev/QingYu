# 本地文件笔记库：妙言行为契约

参考妙言 `9ce84b01bd5f6b23a7156e317b2a34a464e3df76`，只移植文件笔记库相关行为，不改编辑/预览渲染。

| 功能 | 事实源 | 应用契约 |
| --- | --- | --- |
| 新建 | `Note.init`、`NameHelper.getUniqueFileName` | 所选文件夹创建 `.md`；空名称用大写 UUID，界面显示“无标题”；文件存在后才显示成功 |
| 名称 | `NameHelper`、`Note.getFileName` | 去首尾空白，`:` → `-`，`/` → `:`；标题从文件名去扩展名并还原 `:` → `/`，不随正文标题自动改变 |
| 创建冲突 | `NameHelper` | 保留已有文件，查找 `名称 1.md`、`名称 2.md`；数字尾缀按原 helper 收回基础名再查找 |
| 副本 | `Note.getDupeName`、`ViewController.duplicate` | 先提交最新编辑；` Copy`、` Copy 2`；复制原文，不重写 Markdown |
| 导入 | `collectImportableFiles`、`copyFile`、`AppDelegate.importNotes` | 文件或文件夹多选；递归扫描 `.md/.markdown/.txt`，大小写不敏感；跳过隐藏项、`i/files/.Trash` 和目录符号链接；解析真实路径去重并排序；保留源文件，将副本平铺导入主文件夹；已在库中的文件直接选中；重名用 ` Copy`、` Copy 2`，打开最后成功项 |
| 重命名 | `Note.renameFile`、`saveTitle` | 保留扩展名，正文及时间不变；允许仅大小写变化；空名和已有同名拒绝覆盖；文件移动成功后再更新 UI |
| 保存 | `Note.executeSave/writeReplacingExistingFile` | 写入临时文件并原子替换；已被外部删除的文件不能因保存重新出现；外部修改或损坏/不可读内容不得被旧编辑缓冲覆盖；关闭前提交未保存编辑 |
| 移动/废纸篓 | `Note.move`、`Storage.checkLibraryTrash` | 同步移动真实文件；冲突走创建规则；本机 `Trash/` 可恢复，不永久删除 |
| 外部变化监听 | `FileWatcher`、`FileSystemEventManager` | 递归监听当前笔记库；合并事件后复查文件是否仍存在，原子替换按修改处理；导入新路径、移除旧路径；待保存/输入法组合输入时保留一个 1.6 秒复查；当前编辑内容被外部版本替换前备份，清空旧撤销历史；切换目录后更换监听并拒绝旧目录事件 |

新增稳定事实集中在 Rust 文件存储层：笔记路径、名称分配、导入扫描、事务日志与磁盘提交。TypeScript Notebook 负责内存快照及串行提交，界面不自行拼接路径。正文以真实 Markdown 文件为准；隐藏元数据只保存 ID、路径、置顶、时间、选择及同步状态，不保存正文。旧 localStorage 仅作为首次迁移输入和保留备份。

默认笔记目录为 `文稿/MiaoYan Editor`，与原版妙言隔离；可通过选择目录打开已有笔记库。首次迁移在隐藏暂存目录完整写入并核对后再发布元数据；已有目录中的文件不覆盖。未完成事务在下次打开时恢复，恢复失败则阻止写入并保留日志。

对照证据：`NameHelper-reference.swift` 直接拼入原版 `NameHelper.swift`，18 组中文、数字尾缀、斜杠、组合字符和 Emoji 的运行结果固定在 `src-tauri/src/file_library/namehelper-reference.json`；Rust 按该结果测试。macOS 保存和导入沿用 `COPYFILE_METADATA`，并用 Rust `FileTimesExt::set_created` 还原创建时间，覆盖权限及创建时间测试。

边界：桌面导入入口分为“导入文件”和“导入文件夹”，两者均支持多选；原版 NSOpenPanel 可以在同一窗口混选。库扫描不跟随目录符号链接；控制字符、以点开头的名称会拒绝，避免生成扫描不到的隐藏笔记。编码检测使用 Rust chardetng，未逐编码复刻 Foundation 检测器；导入不改原始字节，不确定/损坏文本保持只读。手机目录使用应用私有文件目录，手机测试保持暂停；Windows、Linux 及其他文件系统尚未实测。

外部监听归属 `file_library/external.rs`，使用 notify 的桌面原生后端（macOS 为 FSEvents），150 毫秒合并事件，持续事件最多等待 1 秒。事件只触发复查，不依据“删除”标记直接删除文件或仅依据标记修改列表；以既有扫描器读取的当前磁盘状态为准。应用自身保存、隐藏元数据、冲突备份不会引起无变化的编辑器重建。Notebook 串行接收快照，丢弃外部快照到达前排队的旧保存，列表保留搜索和文件夹范围；只有当前笔记正文/身份/只读状态改变时才重新填充编辑器。

目录事件对照 `Storage.subfolders(of:)`、`Storage.relocateFolder` 和 `StorageRelocationTests`：新建空目录、带内容的目录移入、新旧父子层级、整树改名/移动和移除都重新核对。原版 `FileSystemEventManager` 的入口仍按笔记扩展名过滤，因此目录事件本身覆盖不足；这里沿用其目录枚举及整树迁移语义补齐，而不复制漏监听行为。运行期间用目录的卷/文件标识关联原目录，改名或库内移动后保留文件夹与后代笔记 ID、置顶、选中项和展开状态，笔记继续保存到新路径；旧路径即使立即被新目录占用，也不继承旧笔记身份。所选文件夹移入折叠分支时展开新祖先，搜索条件保留。目录移出笔记库或删除后移除整树，先备份未保存正文，不重建已删除目录。

目录身份缓存只在当前会话使用，不写入或同步平台文件标识；离线移动后重启、跨卷复制式移动、Windows 等无法关联目录身份的情况按旧路径移除/新路径发现处理。当前已使用的笔记库根目录整体移走或删除仍需重新选择目录，不会猜测新位置。

冲突备份沿用原版隐藏目录 `.miaoyan-conflicts`，不进入笔记列表。文件名包含文件夹、原文件名、时间戳及 UUID，避免同一时刻的备份互相覆盖；保留 UTF-8 编辑缓冲。原版会清理超过 100 份且超过 30 天的旧备份，这里保留备份、不自动删除。外部删除且本地有未保存正文时，也先备份再移除旧笔记；备份失败则保留当前编辑缓冲并重试，不能静默丢弃。网络盘能否可靠报告事件取决于文件系统，仍可手动重新读取。

构建验收快照必须包含完整 `public/`，特别是 `public/vditor/dist/` 下的运行时脚本和字体；只忽略项目根目录 `/dist/`，不能用泛化的 `dist/` 规则排除内置编辑器资源。代码测试与原生资源加载都通过后，才能以该快照交付。

实现复核：文件名分配、真实文件操作、迁移和提交都归属 `file_library.rs`；界面不自行生成磁盘路径。正文自动保存不会提前提交正在输入的名称；切换、同步和退出才提交名称。所有 Notebook 更改串行执行，延迟保存绑定原笔记 ID；失败保留完整内存快照。桌面退出先禁用继续输入，再等待文件和标题提交，失败则恢复编辑。
