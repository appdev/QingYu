# QingYu

[简体中文](../../README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Português do Brasil](README.pt-BR.md) · [Italiano](README.it.md) · **Русский**

QingYu — независимое приложение для заметок в Markdown, которое сохраняет записи на вашем устройстве. Откройте папку и начните писать. Каждая заметка хранится в обычном файле `.md`, который можно редактировать и в других программах.

[Скачать QingYu](https://github.com/appdev/QingYu/releases/latest)

![Одна и та же заметка о поездке на Mac и iPhone с таблицей маршрута и списком дел](../../docs/images/hero.webp)

## Работа с заметками

- Редактируйте заголовки, таблицы и списки задач прямо в тексте. Чтобы вставить блок, введите `/`. Формулы, блок-схемы Mermaid и интеллект-карты Markmap отображаются в самой заметке.
- Разложите заметки по папкам и находите нужные фразы с помощью полнотекстового поиска. Планы удобно записывать в заметку дня, а удалённый абзац можно вернуть из истории версий.
- На телефоне панель над клавиатурой позволяет форматировать текст и прикреплять файлы. Заметку целиком или выделенный отрывок можно скопировать или сохранить как изображение.
- В разделе «Настройки → Основные → Язык» можно выбрать один из 11 языков интерфейса или использовать язык системы. Тема, шрифт и размер текста также настраиваются.
- На Mac можно быстро создать заметку из строки меню. Чтобы дать ИИ-инструменту доступ на чтение и запись заметок, включите службу MCP в настройках.

## Хранение и синхронизация

Для локальной работы аккаунт не нужен. Чтобы синхронизировать устройства, подключите QingYu Cloud или собственное S3-совместимое хранилище. Приложение шифрует заметки и вложения на устройстве перед отправкой. Если изменения одного фрагмента на двух устройствах конфликтуют, оно сохраняет отдельную копию.

Сохраните пароль синхронизации. Если вы забудете его и потеряете доступ ко всем разблокированным устройствам, расшифровать данные в облаке будет невозможно. [Руководство по синхронизации (на китайском)](../../docs/s3-sync.md)

## Установка и размещение на своём сервере

| Платформа | Пакет |
| --- | --- |
| macOS · Apple Silicon / Intel | `aarch64.dmg` / `x64.dmg` |
| Windows · x64 | `x64-setup.exe` |
| Linux · x64 | `.deb` / `.AppImage` · WebKitGTK 4.1 |
| Android · arm64 | `.apk` |
| iOS | [Сборка из исходного кода](../../docs/development.md) |
| Веб-версия для своего сервера | Docker · Linux amd64 / arm64 |

Приложение для macOS не прошло нотариализацию Apple. При первом запуске может понадобиться разрешение в разделе «Системные настройки → Конфиденциальность и безопасность». Установщик Windows не подписан и может вызвать предупреждение SmartScreen.

Веб-редактор читает и записывает заметки в папку, смонтированную на сервере. При развёртывании задайте пароль доступа. [Руководство по развёртыванию (на китайском)](../../docs/api-service.md)

## Локальная разработка

Установите Node.js, Rust 1.96.0 и системные зависимости Tauri 2, затем выполните команды из корня репозитория.

```sh
npm ci
npm run tauri dev
```

[Системные требования Tauri](https://v2.tauri.app/start/prerequisites/) · [Руководство по разработке и выпуску (на китайском)](../../docs/development.md)
