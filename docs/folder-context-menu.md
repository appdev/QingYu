macOS 使用 Tauri 原生菜单、SF Symbols 和 NSAlert 输入窗口；重命名在文件夹行内完成。移动使用原生目录选择窗口，只允许同一库内的目录，拒绝重名、自身后代、隐藏目录、附件目录、应用包及符号链接路径。操作前保存编辑内容，操作期间阻止同步、导入、切库等重入。

文件夹以整个目录移动，保留附件、未知文件、子目录和笔记 ID。目录事务使用原有写锁、独占移动和索引版本，并记录目录身份，崩溃后恢复未提交移动；恢复遇到占用或外部替换时保留文件和日志。删除移到系统废纸篓，不永久删除。与妙言的兜底不同，系统废纸篓不可用时本实现报错保留原目录，不将完整目录塞进应用笔记废纸篓。

当前系统 Finder、终端、系统废纸篓接入范围为 macOS。网页环境用于交互测试，可新建和重命名；不会模拟本地文件已被移动或删除。手机测试保持暂停。

## 子文件夹展示、创建和交互复核

同一参考提交另核对了 `Sidebar.swift`、`SidebarTableRowView.swift`、`Storage.subfolders(of:)`、`ViewController+Data.isInScope`、`ShellModel.toggleExpanded` 和 storyboard：

- 真实父子层级，按每一层的名称排序，深度优先排列；只有含子目录的行有展开箭头。
- 原版行高 32pt、每级缩进 14pt；选中底板也随层级缩进，水平内缩 6pt、垂直 3pt、圆角 8pt。保留已要求的目录计数。
- 默认收起；展开状态按笔记库保存。这里按稳定目录 ID 保存，重命名或移动后保留原分支状态；移动选中目录时展开目标祖先使其可见。
- 选中父目录包含后代目录的笔记。收起祖先且当前选择在其后代时，改选该祖先；左右键展开/收起或返回父目录，上下键选择可见行。
- `addProject` 在库根下创建；`newSubfolder` 在当前右键选中的目录下创建。`addChild` 实际只刷新并还原展开/选择；源码里的“Auto expand”注释没有对应实现，不能据此强行展开或改选新目录。本实现按实际行为保留选择和展开状态。
- 右键箭头与右键目录行使用同一目录作为目标，不改变展开状态。箭头使用目录行之外的独立按钮，避免嵌套按钮吞掉输入控件；展开、切换或创建前提交未完成的行内重命名。

上次只验证了菜单功能，遗漏了文件夹树的状态和几何。此次把对照边界扩大到层级、选择、创建完成后的状态和深色底板；没有改全局指令或记忆。验证脚本及结果位于 `artifacts/folder-tree/`，契约用例位于 `tests/folder-tree.test.ts`。
